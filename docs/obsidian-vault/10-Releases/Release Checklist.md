# RuleRoom 1.0 — критерии выпуска

Дата baseline: 23 октября 2026, `main@2d2c3b9`, **0.3 alpha**. Пустой пункт означает отсутствие нужного подтверждения, а не обязательно дефект. Документ не разрешает публикацию. Ответственный за выпуск сверяет доказательства по точному SHA кандидата, а не по старой успешной сборке.

Уточнение 2026-11-01: проект качества — [[01-Game-Design/Public Release Design]], новые задачи — [[07-Tasks/Roadmap]]. Текущий исследованный кандидат `09843e2` не принят как публичный 1.0. Отмеченные ниже исторические проверки не заменяют свежую приёмку финального SHA. Поддерживаемые устройства и фактическая вместимость явно фиксируются до RC.

## Фундамент

- [x] Свежий отдельный checkout baseline прошёл `powershell -ExecutionPolicy Bypass -File .\Build.ps1`.

## Игровая и сетевая приёмка

- [x] Все 10 правил: локальная техническая матрица Studio завершена на объединённом кандидате PR2+PR3; предупреждение, штатное прохождение, ошибка/урон, таймер, survival-награда и reset. Однократность pickup отдельно подтверждена компонентным mock-тестом. [Уровни доказательств](https://github.com/ikanit1/boblox/blob/test/full-rule-acceptance/docs/RULE_ACCEPTANCE.md).
- [ ] Spinner: углы не дают гарантированный AFK-успех; нормальный прыжок проходит.
- [ ] LaserSweep и Spinner: правильные прыжки проходят без урона в согласованной матрице avatar/FPS/network; проверены намеренные попадания, политика HP/регенерации и границы визуала.
- [ ] SafeZone/цвет/исчезающий пол/лава: все поддерживаемые стартовые позиции имеют достижимый безопасный путь; увеличение карты не оставило прежние недостаточные таймеры.
- [ ] Полные Main-забеги с настоящими профилями актуального разрешённого режима повторены после последней правки движения/финала;0/6, успех, пропуск финала и второй забег согласованы с ledger.
- [x] Reactor: solo/team успех, недостаток заряда, charge→all-dead, личные 4+finale; итог и награды согласованы в зафиксированных сценариях.
- [ ] Reactor: отдельные уходы непосредственно до/после зарядки финала и границы итогового начисления.
- [ ] 1/2/несколько/12 игроков в подходящем окружении; число реальных клиентов указано.
- [ ] Заявленный cap, Max Players целевого place и admission согласованы. Если выпускается меньший cap, решение явно зафиксировано; проверка 2 не обозначается как поддержка 12.
- [ ] Late join, leave последнего живого, Reset, respawn, пустой сервер и повторный забег не зависают.
- [x] Два native-клиента: 27 lifecycle-команд/147 проверок; настоящий Main: выход с голосования, выход последнего участника, Waiting и возвращение нового клиента. Reset проверен инъекцией смерти; ручное меню Reset и нагрузка 4–12 сюда не входят.
- [ ] Быстрые/повторные/неверные remotes и одновременные pickup/purchase/quest не дают лишних наград.
- [ ] Нет взаимного выталкивания, нарушающего позиционные правила; коллизии с ареной сохранены.
- [ ] Все временные объекты, таймеры, гравитация, camera/health listeners и UI очищаются/восстанавливаются.

## Данные

- [x] Локальные сценарии настоящего ProfileService с управляемым хранилищем прошли на baseline; это не облако.
- [ ] Отдельно разрешены приватная тестовая публикация и API-доступ; указаны test IDs/store/SHA.
- [ ] Coins/XP/Wins/quests/owned/equipped пережили переход в новый реальный сервер с точной сверкой.
- [ ] Проверены autosave, leave/shutdown, быстрый rejoin, lease conflict, failure fallback без overwrite.
- [ ] Миграция и rollback не теряют прогресс; production store не использовался для разрушительных сценариев.
- [ ] При Busy/Unavailable/fallback/lease loss игрок до значимого прогресса понимает, что сохранение не подтверждено; нет ложного Saved или overwrite временными данными.

## Удобство и представление

- [ ] Наблюдаемые новички понимают первое правило, первую смерть и возврат без объяснения разработчика.
- [ ] Достоверные голос/личный результат/награды, читаемые предупреждения и свободные touch controls.
- [ ] Compact HUD сохраняет причину смерти, возврат, личный результат и следующую цель; личные 4/6 не смешиваются с общим реактором; поздний вход не выдаётся за поражение.
- [ ] Финальный кандидат проверен на desktop и поддерживаемых landscape-размерах эмулятора.
- [ ] Физический телефон: управление, safe areas, читаемость, кадры и нагрев; модель устройства записана.
- [ ] Настоящий геймпад при заявленной поддержке: focus, Activated, вкладки, scrolling, B/закрытие и возврат к игре. Иначе платформа явно исключена из первого выпуска; не выдавать NOT RUN за PASS.
- [ ] Reduced motion, цвет+символ+текст, отсутствие обязательного звука для решения испытания.
- [ ] Звуки прослушаны на колонках/наушниках; mute/respawn/два клиента и естественный финал проверены.
- [ ] Происхождение и права каждого ассета подтверждены; платформенные предупреждения исследованы и классифицированы.

## Производительность и продукт

- [ ] Профили CPU/GPU/memory/network записаны на целевых устройствах и сервере при целевом количестве игроков.
- [ ] Серия забегов не показывает накопления временных Instances, подписок, аудиоголосов и памяти сверх согласованного диапазона.
- [ ] Воронка первых сессий доставляется, dedupe работает; Studio fixture не выдан за production analytics.
- [ ] Воронка учитывает Results при 0/6, отличает добровольное повторное участие от автозапуска/AFK; новая семантика событий версионирована.
- [ ] Внешний плейтест проведён; ошибки понимания и желание второго забега записаны. D1/D7 измеряются после реального доступа, не предсказываются по CI.

## Ограниченный выпуск и откат

- [ ] Есть отдельное разрешение пользователя на выпуск; paid products отсутствуют либо отдельно разрешены и проверены.
- [ ] Проверены owner/group, доступ, ограничения устройств, возрастная доступность, актуальные требования Roblox, описание, иконка и обложки.
- [ ] Для планируемой аудитории младше 16 проверены актуальные требования и состояние Audience Reach/Kids and Select, отдельно от технической готовности build. [Официальные требования](https://create.roblox.com/docs/production/publishing/kids-and-select).
- [ ] Candidate SHA/tag, контрольная сумма build, manifest инструментов и предыдущая проверенная сборка сохранены.
- [ ] Для rollback указаны версия place и совместимость профилей; возврат не перезаписывает новую схему старым кодом.
- [ ] Ограниченный круг игроков получил проверенную сборку; просмотрены ошибки, сохранения, полный цикл и устройства.
- [ ] Решение о публичном 1.0 принято по результатам ограниченного запуска; назначен способ фиксировать/исправлять дефекты.

Текущие внешние зависимости: разрешение на приватную тестовую публикацию/API, реальный телефон и геймпад, независимые игроки, подходящее окружение для 12 клиентов. Их нельзя заменить записью «всё протестировано». До закрытия release gates сборка остаётся альфой/кандидатом.
