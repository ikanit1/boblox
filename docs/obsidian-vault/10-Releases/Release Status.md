# Статус выпуска

## Пакет локальной передачи

Основная игра содержит 12 испытаний и все новые функции следующего прохода. Офлайн пакет build/RuleRoom-LocalCandidate.zip содержит место, идентичность и документы, но не публикует его. [PRODUCT_COMPLETION](../../PRODUCT_COMPLETION.md), [передача и описания](../../release/README.md). Схема v5 исключает сохранение старым v4 writer; аварийное отключение новых правил доступно без отката данных. Commit/CI/публикация и реальные release gates остаются открытыми.


## Текущий локальный кандидат — 8 ноября 2026

После roadmap-пакета Build создаёт `build/candidate-manifest.json` с хешами входов и rbxlx. `candidateCommit=null` при грязном дереве; native/device/cloud/capacity/human помечены `not_attested`. Это идентичность локального артефакта, не релизная приёмка. `ServerStorage.RuleRoomControls` позволяет остановить новый забег при недопустимой колоде; выключение обязательного финала запрещает старт, а текущий забег не меняется. Флаги только в одном сервере, не глобальный rollout. Финальные настройки/place/cap/откат требуют отдельной настоящей репетиции. Публикация по-прежнему не разрешена. [ROADMAP_PROGRESS](../../ROADMAP_PROGRESS.md).


Продукт остаётся локальной альфой/кандидатом. Техническая приёмка отдельных правил не является публичным 1.0, доказанным удержанием или заработком. Публикация Roblox и Robux-продукты не выполнялись.

Полный канонический gate: [[10-Releases/Release Checklist]]. План с зависимостями: [[07-Tasks/Roadmap]]. Эта заметка не дублирует checkbox-статусы.

Перед ограниченным выпуском нужны закрытые или явно принятые внешние ограничения: multiplayer-матрица, облачный новый сервер/повторный вход, физические устройства, слуховая оценка, независимые игроки, длительная производительность и проверяемый rollback. GitHub PR/CI и запуск place в Studio — разные действия с разными доказательствами.

Обычный локальный вход: Start.cmd → Build → открытие build/RuleRoom.rbxlx → Play. Для текущего результата сверять реальный branch/HEAD, исходники в Studio и SHA построенного place. Исторические place/архивы не заменять автоматически.

Данные QA лежат отдельно от Git; ссылки и ограничения — [[06-Testing/Evidence Index]]. Решения по публикации требуют отдельного согласованного шага после конкретной готовой сборки.
