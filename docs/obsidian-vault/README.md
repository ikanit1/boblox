# База знаний RuleRoom

Откройте эту папку как отдельный vault Obsidian. Начальная страница — [[00-Dashboard/Dashboard|Dashboard]]. Все заметки — обычный Markdown в существующем репозитории [ikanit1/boblox](https://github.com/ikanit1/boblox); отдельного игрового проекта здесь нет.

Исходники `src/`, генератор `tools/build_assets.py` и Rojo mapping определяют фактическую игру. Заметки объясняют решения и связывают доказательства. Единственные актуальные дорожная карта и release checklist находятся в [[07-Tasks/Roadmap]] и [[10-Releases/Release Checklist]]. Их прежние пути в docs оставлены совместимыми указателями.

Правила работы, безопасный CLI и проверка ссылок: Obsidian setup (`docs/environment/obsidian.md`). Личные vault не относятся к проекту; community plugins и платные сервисы не нужны.
