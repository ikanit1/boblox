# Рабочая доска

Единственный список этапов и критериев — [[07-Tasks/Roadmap]]. Эта страница направляет работу и не ведёт второй набор checkbox-статусов.

## Сейчас

По прямому запросу пользователя расширяется скудная карта: поле 84×84, комплекс 180×144, тренировочный паркур, архив правил, смотровая галерея и выбор очереди/прогулки. Владелец исходников и Studio — root. Контракт, world-safety проверки и runtime-регрессия обновляются в этой итерации. Окружение вынесено в отдельный PR6.

## Следующая игровая итерация

Стабилизация multiplayer по открытому Stage 2: оставшиеся lifecycle-переходы и delayed-сценарии, 4/8 native clients после освобождения ресурсов, длительный production performance. 12 клиентов требуют подходящей отдельно разрешённой среды; локальный API отказ не обходить dummy-нагрузкой.

Облачные данные зависят от отдельного разрешения test publication/API. UX, физические устройства, звук и внешний плейтест имеют собственные критерии. Уже начатые WIP-фичи не считать релизными до review и приёмки.

## Карточка задачи

При создании задачи записать проблему/триггер, ожидаемое поведение, конкретные owned files, критерий приёмки, необходимый уровень доказательств и ссылки на решение/PR. Закрывать после проверки результата, не после написания кода. Перед запуском агента прочитать [[09-AI-Skills/Index]] и назначить владельца Studio.
