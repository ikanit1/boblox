## Проверяемые гипотезы

1. Возвращение после каждого испытания уменьшает выходы после смерти относительно выбывания на весь забег.
2. Разные типы действий и голосование увеличивают число повторных забегов относительно фиксированной последовательности.
3. Общий финал создаёт повод играть с друзьями, а видимый личный результат сохраняет соревнование.
4. Достижимая первая косметика помогает понять смысл монет; большой магазин до первого успеха мешает.

Начальный внешний тест: 10–20 добровольцев, наблюдение первого входа, без устных объяснений, запись причины непонимания/выхода, разбивка компьютер/телефон. Затем опубликованный ограниченный тест и данные D1/D7. Цели из GAME_DESIGN — наши гипотезы, не нормы Roblox. Не выдавать локальную проверку за доказанное удержание.

## Перед публичным запуском

Проверить действующие [условия публикации](https://create.roblox.com/docs/production/publishing/publish-experiences-and-places) и [Kids and Select](https://create.roblox.com/docs/production/publishing/kids-and-select) в аккаунте автора, анкету контента, доступность по аудитории, разрешения ассетов, обложки, реальное сохранение и покупки. Детская аудитория из исходной идеи не означает автоматическую доступность новой игры детям. Эти настройки не меняются одним Git push.
