# Кадры для будущей страницы игры

Сначала снять **текущий** кандидат. Исторические `docs/media` сохраняют свои даты и не являются изображениями нового интерфейса/контента. Не дорисовывать на обложке отсутствующие механики и не выдавать концепт за кадр игры.

| Материал | Содержание | Готовность |
|---|---|---|
| Иконка | Крупный реактор, четыре плитки с символами, один прыгающий персонаж; читается без мелкого текста | Ожидает кадра текущего кандидата и визуальной оценки |
| Обложка 1 | Реальный прыжок через луч; видны ноги, луч и безопасное приземление | Ожидает съёмки |
| Обложка 2 | Волна давления: экран и зелёная полоса за ним, участник в укрытии | Ожидает съёмки |
| Обложка 3 | Стена с проёмом и совместная стабилизация реактора | Ожидает съёмки |
| Ролик 20–25 секунд | 0–3 правило меняется; 3–8 прыжок/укрытие; 8–13 проём; 13–19 командный финал; 19–25 итог и новая попытка | Ожидает настоящей записи игрового процесса |

Сохранять исходный кадр, fingerprint места, дату, состав реальных игроков и использованные материалы. Не показывать имена тестеров без согласования. Текст/музыка не должны скрывать реальный результат прохождения.

Для иконки Roblox рекомендует квадрат не меньше 512×512; уменьшенную версию отдельно оценить на 150×150. [Официальная документация иконок](https://create.roblox.com/docs/production/publishing/experience-icons).

Для обложки подготовить 16:9, желательно 1920×1080. Видео должно правдиво показывать игру; небольшая цветокоррекция и логотип допустимы без подмены механик. [Официальная документация обложек и видео](https://create.roblox.com/docs/production/publishing/thumbnails). Проверено 8 ноября 2026; требования повторно сверить перед фактической загрузкой.
