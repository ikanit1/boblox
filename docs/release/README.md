# Передача локального кандидата

Это пакет для проверки готовой реализации, не разрешение на публикацию. Открывать `build/RuleRoom.rbxlx`: он содержит основную игру, включая новые испытания. Экспериментальное место не нужно для обычной игры и в этот архив не включается.

`package-receipt.json` содержит контрольные суммы файлов. `build/candidate-manifest.json` связывает место с исходниками и инструментами. У незакоммиченного кандидата `candidateCommit` остаётся `null`; базовый HEAD не выдаётся за версию всех изменений. Проверка ZIP не заменяет запуск игры.

Описание на русском и английском подготовлено в [listing.json](listing.json). Это текст для будущего ограниченного выпуска после приёмки. Заявленная вместимость в нём намеренно отсутствует: сервер допускает 12, но 12 настоящих клиентов ещё должны пройти проверку.

Порядок дальнейшей приёмки: свежая матрица 12 правил → полные забеги/выход/Reset и финал → устройства и прослушивание → отдельно разрешённое облако → люди → точный commit/CI → разрешённый ограниченный выпуск. Критерии находятся в канонической дорожной карте, а не в ещё одной копии списка.

При откате использовать совместимый с текущей схемой профиля сервер. Старый сервер должен отказать в загрузке более новой схемы; нельзя переименовывать production store, очищать профиль или уменьшать SchemaVersion для обхода отказа. Безопасная временная мера — серверные `Disabled_<RuleId>`; отключение новых правил не требует отката схемы данных.

Все новые модели, схемы обучения и декоративные темы созданы из исходников проекта. Новых внешних ассетов, платных продуктов и загруженных в Roblox материалов в этом пакете нет. Реальные рекламные кадры готовятся по [MEDIA_PLAN](MEDIA_PLAN.md) после запуска текущего кандидата.
